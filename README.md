# 國中英文單字總複習互動系統

一套以低操作摩擦、即時回饋與錯題重練為核心的國中英文單字複習網頁。

系統目前提供單字卡、英選中、中選英與例句克漏字四種模式，並可依國中英文冊別與補充等級選擇學習範圍。

## 專案目的

本專案主要提供國中生進行英文單字總複習，希望透過簡單操作、即時鼓勵與錯題循環重考，降低開始背單字的心理阻力。

系統的設計方向包括：

* 不需登入即可開始使用
* 手機與電腦皆可操作
* 可自由選擇學習範圍
* 答錯後立即顯示完整解析
* 錯題會再次出現，直到全部答對
* 顯示初始正確率與總作答次數
* 使用發音、音效、動畫與鼓勵文字增加互動感

## 目前功能

### 1. 單字卡瀏覽

單字卡正面顯示：

* 英文單字
* 詞性
* 動詞過去式與過去分詞
* 英文發音按鈕

翻到背面後顯示：

* 中文意思
* 英文例句
* 中文例句
* 動詞變化資訊

使用者可以切換上一張與下一張單字卡。

### 2. 英選中測驗

題目顯示英文單字，並保留題目上的冊別與詞性，維持詞性學習資訊。

四個作答選項只顯示中文意思，不顯示詞性，避免學生利用選項詞性直接排除答案。

題目出現時仍可自動播放英文發音，但會受到獨立的語音開關控制。

### 3. 中選英測驗

顯示中文意思，從四個英文單字中選擇正確答案。

中選英測驗會隱藏題目發音按鈕，避免發音直接透露正確英文答案。

### 4. 例句克漏字測驗

將英文例句中的目標單字或時態變化挖空，再從四個英文單字中選出答案。

克漏字模式目前具有以下限制：

* 僅開放 B5、B6 與補充 LV1～LV4
* 自動停用 B1～B4
* 自動排除片語
* 隱藏題目發音，避免直接透露答案
* 可自行開啟或隱藏中文例句提示

### 5. 學習範圍選擇

目前可選擇：

* 第一冊 B1
* 第二冊 B2
* 第三冊 B3
* 第四冊 B4
* 第五冊 B5
* 第六冊 B6
* 補充 LV1
* 補充 LV2
* 補充 LV3
* 補充 LV4

可以同時選擇多個範圍，也可以使用全選功能。

### 6. 題數設定

一般測驗可選擇：

* 20 題
* 30 題
* 50 題

若所選範圍的可用單字少於指定題數，系統會使用實際可用的全部單字。

### 7. 錯題重練

學生答錯後，系統會顯示：

* 正確英文單字
* 詞性
* 中文意思
* 動詞過去式與過去分詞
* 英文例句
* 中文例句

答錯的題目會移到題目佇列最後，稍後再次出題。必須答對所有題目後，才會完成挑戰。

### 8. 成績統計

完成測驗後會顯示：

* 第一輪初始正確率
* 包含錯題重考的總作答次數

初始正確率只統計每個單字第一次回答的結果。

### 9. 發音、音效與動畫

系統目前包含：

* 美式英語單字發音
* 答對音效
* 答錯音效
* 完成挑戰音效
* 頁面頂部具有獨立的語音控制與音效控制
* 語音控制英文 TTS 朗讀，包括單字卡發音及英選中的自動與手動發音
* 音效控制答對、答錯及完成挑戰提示音
* 語音與音效預設都為開啟，兩者可以獨立切換且互不影響
* 重新整理網頁後，語音與音效會恢復預設開啟
* 關閉語音時，畫面上的發音按鈕仍保留，但不播放語音
* 答錯震動效果
* 答對發光效果
* 單字卡翻牌動畫
* 完成挑戰五彩紙屑動畫

## 題庫來源

系統啟動時會優先從已發布的 Google Sheets CSV 題庫載入資料。

如果網路連線、CSV 解析或跨來源存取發生問題，系統會自動改用程式內建的備援題庫，避免頁面無法使用。

## 題庫欄位格式

Google Sheets 第一列應使用以下欄位名稱：

| 欄位                | 說明      |
| ----------------- | ------- |
| `word`            | 英文單字或片語 |
| `past_tense`      | 動詞過去式   |
| `past_participle` | 動詞過去分詞  |
| `part_of_speech`  | 詞性      |
| `translation`     | 中文意思    |
| `level`           | 冊別或補充等級 |
| `example_en`      | 英文例句    |
| `example_ch`      | 中文例句    |

`level` 欄位目前支援：

* `B1`
* `B2`
* `B3`
* `B4`
* `B5`
* `B6`
* `等級 1`
* `等級 2`
* `等級 3`
* `等級 4`

## 使用技術

本專案目前採用：

* HTML
* Tailwind CSS CDN
* Vanilla JavaScript
* Google Sheets CSV
* Web Speech API
* Web Audio API
* Canvas API

目前所有主要畫面、樣式、題庫處理與測驗邏輯都集中在 `index.html`。

## 執行方式

本專案為純前端網頁，不需要安裝套件或建置工具。

可以直接部署至：

* GitHub Pages
* Vercel
* Netlify
* 其他靜態網站服務

本機測試時，建議使用本地 HTTP Server 開啟，不建議只以 `file://` 方式直接開啟 HTML，避免瀏覽器的跨來源或安全性限制影響 Google Sheets 題庫讀取。

## 專案檔案

目前主要檔案：

```text
English-App_V2/
├── index.html
├── README.md
└── CHANGELOG.md
```

* `index.html`：網頁應用程式本體。
* `README.md`：專案功能、題庫格式、執行方式與後續方向。
* `CHANGELOG.md`：重要修改與版本變更紀錄。

## 後續改善方向

評估中的後續方向包括：

* 增加自動化測試

* 改善單一單字克漏字挖空準確度
