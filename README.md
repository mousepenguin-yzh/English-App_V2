# 國中英文單字總複習互動系統

一套以低操作摩擦、即時回饋與錯題重練為核心的國中英文單字複習網頁。

系統目前提供單字卡、英選中、中選英、例句克漏字與中翻英拼字測驗五種模式，並可依國中英文冊別與補充等級選擇學習範圍。

## 專案目的

本專案主要提供國中生進行英文單字總複習，希望透過簡單操作、即時鼓勵與錯題循環重考，降低開始背單字的心理阻力。

系統的設計方向包括：

* 不需登入即可開始使用
* 手機與電腦皆可操作
* 可自由選擇學習範圍
* 答錯後立即顯示完整解析
* 錯題會再次出現，直到全部答對
* 顯示初始正確率與總作答次數
* 使用發音、音效、動畫與鼓勵文字增加互動感

## 目前功能

### 1. 單字卡瀏覽

單字卡正面顯示：

* 英文單字
* 詞性
* 動詞過去式與過去分詞
* 英文發音按鈕

翻到背面後顯示：

* 中文意思
* 英文例句
* 中文例句
* 動詞變化資訊

使用者可以切換上一張與下一張單字卡。

### 2. 英選中測驗

題目顯示英文單字，並保留題目上的冊別與詞性，維持詞性學習資訊。

四個作答選項只顯示中文意思，不顯示詞性，避免學生利用選項詞性直接排除答案。

題目出現時仍可自動播放英文發音，但會受到獨立的語音開關控制。

### 3. 中選英測驗

顯示中文意思，從四個英文單字中選擇正確答案。

中選英測驗會隱藏題目發音按鈕，避免發音直接透露正確英文答案。

### 4. 例句克漏字測驗

將英文例句中的目標單字或時態變化挖空，再從四個英文單字中選出答案。

克漏字模式目前具有以下限制：

* 僅開放 B5、B6 與補充 LV1～LV4
* 自動停用 B1～B4
* 自動排除片語
* 隱藏題目發音，避免直接透露答案
* 可自行開啟或隱藏中文例句提示

### 5. 中翻英拼字測驗

顯示經審核的中文提示、詞性與冊課資訊，使用英文輸入框作答，可按送出或鍵盤 Enter。判題忽略大小寫及首尾空白，彎／直撇號視為相同，但不能漏寫撇號；字母、字內空格及連字號仍須正確，不接受模糊拼字。完整固定句子可保留或省略原句尾標點；時間縮寫題會明示要求縮寫，點號須全部保留或全部省略。空白答案不能送出，回饋期間鎖定送出以免重複計分。答錯使用既有解析與稍後重考流程。

若答出該提示已確認的替代答案（例如 beautiful 題回答 pretty），顯示正向回饋及答對音效，按繼續後將原目標移到隊尾一次。重練會明示目標字的首字母與字元數；再次回答同義字時顯示完整目標，留在當題照著拼寫，不再反覆移到隊尾。必須拼出目標字才完成。所有有效送出都計入總次數；只有首次直接拼出目標字才計入首次目標拼寫正確率，替代答案不算拼錯但不計入該比率，重練答對不回補。PR #7 的完整變體題仍可答任一合法變體直接完成。

此模式會依整份題庫保守篩選（不受目前選取範圍影響）：

* 中文義項以分號或頓號分隔。一般題維持原衝突排除；逐筆審核清單優先縮小為原有的明確義項，或有限接受確認過的同詞性替代答案。不是僅憑中文字面不同就恢復，也不任意交叉配對多詞性。來源中文義項集合或詞性變更時，審核列退回排除。
* 依實際提示及全題庫檢查：若對應本題不接受的其他英文答案，仍排除，即使另一答案在不同冊課。不支援的格式列也參與檢查；新衝突不能因格式不支援而被忽略。
* 保留一般單字、片語、撇號及內部連字號。詞性為 `phr.`、句內符合一般拼寫格式的多字固定句，可省略原有單一句尾 `.?!`；不能刪除任意內部標點或佔位省略號。
* `a.m.`／`p.m.` 僅在詞性及中文義項符合已確認的時間提示時恢復；接受 `a.m.`／`am` 或 `p.m.`／`pm`，不接受部分漏點號或完整片語替代縮寫。
* 僅確認 `autumn / fall`（秋天／n.）、`everyone (everybody)`（每個人；各位／pron.）、`though / although`（雖然／conj.）三組完整變體；原英文欄位、中文義項集合及詞性都須符合，才接受任一完整答案。中文或詞性改變時重新排除，不會自動拆解任意斜線或括號。
* `may / might`、`will / would` 的時態／情態差異缺乏上下文，繼續排除；`Mr.` 的「先生」仍與 `sir` 衝突。佔位片語（如 `show ... around`）、構詞字尾（`-free`、`-sounding`）及 `year(s) old` 也保持排除。
* 排除缺少中文或詞性的資料，同冊課、答案、詞性及中文完全相同的資料只出一題。

篩選不會改動題庫或其他四種模式。單字池顯示實際可用題數；沒有適用題目時維持設定頁並提示選擇其他範圍。此規則不能辨識所有語意相近但中文寫法不同的同義字；建議老師持續抽查題目。

2026-10-30 公開 CSV 快照共 2,054 筆，本次特殊格式調整將可用題數由 1,731 增加到 1,743（新增 12 題、未移除原可用題）。新增為彎撇號 1 題、時間縮寫 2 題、固定句子 6 題與已確認完整變體 3 題；後續題庫更新會重新計算。多答案仍算一題，答出其中一個合法答案不代表已練過所有變體。

同日中文義項審核再恢復 17 題，可用題數 1,743 → 1,760，原可用題目未減少。包含 class／heavy／cell 縮小義項，以及 beautiful／pretty／lovely、smart／clever／intelligent、sofa／couch、trash／garbage、movie theater／cinema、yummy／delicious 的有限替代答案；lovely 同時縮小為「漂亮的」。[逐題依據、維護規則、計分案例及手機驗收](docs/spelling-review.md) 另列完整說明。

### 6. 學習範圍選擇

目前可選擇：

* 第一冊 B1
* 第二冊 B2
* 第三冊 B3
* 第四冊 B4
* 第五冊 B5
* 第六冊 B6
* 補充 LV1
* 補充 LV2
* 補充 LV3
* 補充 LV4

可以同時選擇多個範圍，也可以使用全選功能。

若某一冊的題庫具有非空白 `lesson`，該冊右側會出現展開按鈕，可勾選整冊、單一課次或多個課次。整冊勾選會包含所有課次；若該冊同時有未填課次的單字，展開區也會顯示「未分課」。只選部分課次時，冊別會以半勾選狀態提示目前範圍。沒有 `lesson` 欄位或整冊課次皆空白時，仍維持原本只選冊別的操作。

### 7. 題數設定

一般測驗可選擇：

* 20 題
* 30 題
* 50 題

若所選範圍的可用單字少於指定題數，系統會使用實際可用的全部單字。

### 8. 錯題重練

學生答錯後，系統會顯示：

* 正確英文單字
* 詞性
* 中文意思
* 動詞過去式與過去分詞
* 英文例句
* 中文例句

答錯的題目會移到題目佇列最後，稍後再次出題。必須答對所有題目後，才會完成挑戰。

### 9. 成績統計

完成測驗後會顯示：

* 第一輪初始正確率
* 包含錯題重考的總作答次數

初始正確率只統計每個單字第一次回答的結果。拼字模式使用「首次目標拼寫正確率」及相應說明，總作答次數也包含合理替代答案與重練。

### 10. 發音、音效與動畫

系統目前包含：

* 美式英語單字發音
* 答對音效
* 答錯音效
* 完成挑戰音效
* 頁面頂部具有獨立的語音控制與音效控制
* 語音控制英文 TTS 朗讀，包括單字卡發音及英選中的自動與手動發音
* 音效控制答對、答錯及完成挑戰提示音
* 語音與音效預設都為開啟，兩者可以獨立切換且互不影響
* 重新整理網頁後，語音與音效會恢復預設開啟
* 關閉語音時，畫面上的發音按鈕仍保留，但不播放語音
* 答錯震動效果
* 答對發光效果
* 單字卡翻牌動畫
* 完成挑戰五彩紙屑動畫

## 題庫來源

系統啟動時會優先從已發布的 Google Sheets CSV 題庫載入資料。

如果網路連線、CSV 解析或跨來源存取發生問題，系統會自動改用程式內建的備援題庫，避免頁面無法使用。

## 題庫欄位格式

Google Sheets 第一列應使用以下欄位名稱：

| 欄位                | 說明      |
| ----------------- | ------- |
| `word`            | 英文單字或片語 |
| `past_tense`      | 動詞過去式   |
| `past_participle` | 動詞過去分詞  |
| `part_of_speech`  | 詞性      |
| `translation`     | 中文意思    |
| `level`           | 冊別或補充等級 |
| `lesson`          | 選用課次；可留白   |
| `example_en`      | 英文例句    |
| `example_ch`      | 中文例句    |

`level` 欄位目前支援：

* `B1`
* `B2`
* `B3`
* `B4`
* `B5`
* `B6`
* `等級 1`
* `等級 2`
* `等級 3`
* `等級 4`

`lesson` 為選用欄位，建議放在 `level` 後方。純數字課次會顯示為「第 N 課」並依數值排序；其他文字則原樣顯示。舊題庫不需要加入此欄位，資料列尾端未提供選用欄位也不會被略過。程式會逐冊判斷是否存在非空白課次，不會因其他冊有課次就改變未分課冊別的介面。

## 測試

不需安裝套件即可執行判題、篩選與 CSV 回歸測試（Node.js 18 以上）：

```sh
node --test tests/spelling.test.cjs
```

以公開 CSV 快照比較 PR #7 篩選基準與目前規則，列出新增題目並檢查來源未被修改：`node tests/audit-spelling.cjs path/to/snapshot.csv`。

瀏覽器回歸測試使用 Playwright 與已安裝的 Chrome，不會加入應用程式執行依賴。可先執行 `npm install --no-save --package-lock=false playwright`，再執行 `node tests/browser.cjs`；或以 `PLAYWRIGHT_MODULE` 環境變數指定現有 Playwright 模組路徑。測試透過本機 HTTP server 與固定 CSV 資料驗證完整拼字流程、錯題重練、統計、快速重複操作、重新開始、既有四種模式、冊課範圍、空題庫及 320/375px 畫面。`VOCAB_CSV` 可指定額外 CSV 快照，驗證實際可用題數與完成 20 題測驗；`SCREENSHOT_PATH` 可指定窄螢幕截圖位置，預設輸出到系統暫存目錄。

手機實機人工驗收（瀏覽器模擬無法驗證原生鍵盤）：

1. 在 iOS Safari 與 Android Chrome 開啟拼字模式；確認英文鍵盤、自動大寫、自動修正、建議字及拼字提示狀態。網頁已設定停用提示屬性，但鍵盤 App 可能自行決定是否遵守。
2. 以送出按鈕及鍵盤 Enter 各作答；測試輸入法組字確認鍵、長按 Enter、快速連點，以及連續答對後鍵盤焦點是否合理。
3. 鍵盤展開時確認輸入框與送出鈕可捲動到可見範圍，直向窄螢幕與橫向皆無新增水平溢出。
4. 測試答錯解析、繼續重考、片語空格及撇號／連字號；答對等待期間返回選單並重新開始，確認題數與統計重設。
5. B1 第 5 課測試 `a.m.`／`am`、`p.m.`／`pm`，確認顯示「時間縮寫」提示；`a.m` 等部分漏點號須判錯。補充等級 1 的「點鐘」測試 `o’clock`／`o'clock` 均正確，`oclock` 須錯。可暫時關閉音效方便檢查。
6. B1 第 1 課「很高興認識你。」可答 `Nice to meet you.` 或不含句點；B3 第 3 課「做得好!」可答 `Good job!`／`Good job`，但少字母、雙空格及重複句尾標點須錯。
7. B3 第 1 課「秋天」分別以 `autumn`／`fall` 完成；B1 第 5 課「每個人;各位」以 `everyone`／`everybody` 完成。不要輸入來源的斜線或括號。B4 未分課的「雖然」可答 `though`／`although`。每組至少先答錯一次再答對，確認第一次正確率不回補、總作答次數包含重練，最後可進入結算。

## 專案定位

本系統以降低學生開始複習英文單字的阻力為主要目標，強調小步驟、立即回饋、容許犯錯，以及持續完成所有錯題。
